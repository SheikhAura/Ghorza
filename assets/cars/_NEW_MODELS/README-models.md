# حط الباك هنا 🚗 (باك كامل عادي — متقسّمش حاجة)

## الخطوة الوحيدة
فكّ الـ zip بتاع الباك **زي ما هو** جوه الفولدر ده. يعني هيبقى الشكل كده:

```
assets/cars/_NEW_MODELS/
└── اسم-الباك/                 ← سيب اسم الباك زي ما هو
    ├── FBX/                   ← أو Models/ أو أي اسم
    │   ├── Sedan.fbx
    │   ├── Taxi.fbx
    │   ├── SUV.fbx
    │   └── ...
    ├── Textures/              ← مهمة لو الموديلات محتاجاها
    ├── OBJ/                   (اختياري — لو موجودة سيبها)
    └── License.txt / credits.txt   ← سيبها
```

**متغيّرش أسماء ولا ترتّب ولا تعمل فولدر لكل عربية.** أنا هقرأ الباك بهيكله وأدمجه.

## ممكن تحذف الحاجات دي (بتقلل الحجم وبس)
- فولدر `Blends/` أو `*.blend` (مش بستخدمه).
- ملفات `Preview.png` / `*.psd` / `*.max` / `*.c4d`.
- أي صيغة مش محتاجها: لو الباك فيه `FBX` و `OBJ` و `GLTF` — سيب **واحدة بس** (الأفضل GLB ثم FBX ثم OBJ).

## الباك فيه عربيات كتير؟ عادي جدًا
مهما كان العدد، أنا بعمل كده أوتوماتيك:
- **قراءة**: `node tools/scan_glb.mjs assets/cars/_NEW_MODELS` بيطلّع جدول بكل موديل (المثلثات، الحجم، المقاسات، هل العجل منفصل، الخامات).
- **المعرض**: بيحمّل العربية اللي تختارها بس (lazy load) — مش كل الباك مرة واحدة.
- **الطريق**: بيختار مجموعة عربيات للمرور (٨–١٠) وبيلوّنها عشوائي — نفس الموديل بيتكرر بألوان مختلفة.
- **عربيات اللاعب**: بتاخد أسعار على حسب الفئة (سيدان رخيص → سبورت غالي).

## اللي محتاجه فعليًا
| حاجة | ليه |
|---|---|
| ملفات الموديل (`.glb` / `.gltf+.bin` / `.fbx` / `.obj+.mtl`) | الموديل نفسه |
| التكستشرات (`.png/.jpg`) في نفس الفولدر أو جنبه | الدهان/الزجاج/الشمعات |
| ملف الرخصة لو موجود | للتوثيق |

## اختياري بس بيسرّع (لو حبيت)
اكتب ملف `car-list.txt` جنب الباك فيه سطر لكل عربية:
```
Sedan      | سيدان   | 0      (عربية البداية)
Taxi       | تاكسي   | مرور
SUV        | عائلية  | 4500
Sports     | رياضية  | 9000
Bus        | أتوبيس  | مرور
```
- `مرور` = تبقى عربية مرور في الطريق (مش عربية لاعب).
- الرقم = سعر العربية في المعرض.

**ولو مكتبتش الملف ده:** مش مشكلة — أنا هحدد الأنواع من الأسماء وأبعتلك القائمة قبل ما أظبط الأسعار.

## بعد ما تحط الباك
1. ازِد الـ zip كله (أو ارفع فولدر `_NEW_MODELS` لوحده) — أي طريقة تنفع.
2. أنا هعمل: قراءة الباك → تطبيع المقاسات والاتجاه → معرض سيارات (منصة بتلف + شراء بالفلوس) + محفظة محفوظة + دمج في الفيزيا/التدرك/كسر الزجاج.
3. لو الموديلات عجلها **ملزوق في الجسم** (مش نودات منفصلة) مش مشكلة — هفصله بالكود.
